# Game Privacy Policies

统一维护游戏隐私政策，按游戏名称建目录。默认英文，每个游戏提供简体中文切换。

| --- | --- | --- |

## 新增游戏

1. 使用游戏英文名的小写连字符形式创建目录。
2. 在目录中放置 `index.html`（英文）、`zh.html`（中文）及所需样式和图片。
3. 按该游戏实际功能编写政策，更新生效日期和语言切换链接。
4. 在根目录首页和本表添加游戏入口。

GitHub Pages 从 main 分支根目录发布。广告开关配置仍由独立的 game-remote-config 仓库维护。
