1. 关于本政策

Color Sudoku Garden（彩色数独花园）由 Jocelyn 发布。本政策说明您游玩游戏、使用可选广告功能或联系我们时的信息处理方式。游玩无需注册账户。

2. 设备上的游戏数据

游戏在您的设备本地保存关卡进度、通关记录、星级、种子、花园装饰、解锁主题、设置、未完成棋盘、笔记、撤销记录及奖励记录。本地备份用于恢复存档。我们不提供游戏账户、云端进度或游戏行为分析服务，也不会将这些存档记录上传到我们的服务器。

3. 可选激励广告

移动端版本可通过 Google AdMob 提供自愿观看的激励广告，例如获取提示、增加一次错误机会、额外种子或额外撤销机会。基础通关奖励不要求观看广告。Google 及其广告合作伙伴可能处理 IP 地址、允许使用的设备及广告标识符、由网络信息推断的大致位置、广告互动以及技术或诊断信息，以投放和衡量广告、防范欺诈并维护服务。非个性化广告也可能涉及数据处理。广告是否可用及隐私选择取决于您的地区、设备设置和所使用的版本。

4. 隐私选择

在适用情况下，广告隐私提示会在请求广告前说明可用选项。您可以通过应用内提供的隐私控件及设备设置管理可用的广告权限。拒绝可选权限不会使您失去基础数独玩法的使用权。有关 Google 对广告数据的处理和可用控制方式，请参阅下方链接。

5. 远程配置与本网站

移动端游戏从 GitHub 获取公开的广告配置，请求不包含您的数独进度、种子或花园记录。GitHub 会接收 IP 地址等正常网络连接信息。游戏成功保存有效正式配置后，该安装实例将停止请求该配置，重启后也不会继续请求；移除应用数据可能重置此状态。本政策网站由 GitHub Pages 托管，托管服务商可能处理常规连接和安全日志。我们未在本政策页面添加广告或分析 Cookie。

6. 您主动提供的联系信息

如果您通过邮件联系我们，我们会收到您的邮箱地址以及您选择提供的信息，用于回复请求、调查反馈问题及处理隐私咨询。请勿发送密码或其他不必要的敏感信息。

7. 保留、删除与安全

本地游戏数据保留在您的设备上，直到被替换或移除。删除应用及其数据或清除应用数据可能删除本地进度；操作系统备份可能按您的备份设置保留副本。我们无法通过服务器恢复进度。支持邮件仅在处理请求及履行适用义务所需的期限内保留。广告及托管服务商适用其自身的数据保留规则。我们合理保护控制范围内的信息，但任何存储或传输方式均无法保证绝对安全。

8. 您的权利与跨境处理

根据您所在地区，您可能享有访问、更正或删除个人信息、限制或反对处理、撤回同意以及向相关机构投诉的权利。涉及我们持有的信息时，请联系我们行使权利。我们无法识别或调取仅保存在您设备上的游戏存档。第三方服务商可能依据其隐私条款及适用保障措施，在您所在国家或地区以外处理信息。我们不出售您的支持邮件或本地游戏存档。

9. 儿童隐私

游戏不会要求玩家提供姓名、出生日期或联系方式才能游玩。如果您是家长或监护人，认为儿童已向我们提供个人信息，请联系我们，以便核实并采取适当措施。

10. 更新与联系

当游戏或其数据处理方式发生变化时，我们可能更新本政策。页面顶部的生效日期标识当前版本；如有要求，我们会另行通知。发布主体：Jocelyn。隐私联系邮箱：seansheaton@gmail.com。
