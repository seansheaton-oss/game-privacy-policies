端末に保存する情報

進行状況、星、コイン、アイテム、スキン、設定、デイリー結果、途中の盤面を端末に保存します。アカウント、チャット、運営者のクラウドセーブはなく、ゲームのセーブ情報をゲームサーバーに送信しません。OS の端末バックアップにアプリのデータが含まれる場合があります。

広告と同意

Google AdMob と UMP を組み込みます。広告が有効な場合（テスト広告を含む）、IP アドレスとそこから推定したおおよその位置、端末・アプリ識別子、広告の表示や操作、パフォーマンス、クラッシュ情報などが、広告配信・測定、同意管理、安全性、不正防止のために処理される場合があります。SDK、地域、選択により異なります。非パーソナライズ広告でもデータ処理はあります。現在は非パーソナライズ広告を要求し、パブリッシャーのファーストパーティ ID を無効化し、Apple ATT 許可を要求せず、アプリコードから IDFA を取得しません。Google と広告パートナーは独自のポリシーで処理する場合があります。SDK の開示には設定によって追跡に使える識別子も含まれるため、識別子が一切処理されないとは保証しません。

広告の選択

UMP が同意情報を更新し、必要なフォームを表示してから広告を要求します。「設定 > プライバシーポリシー > プライバシーの選択」で利用可能な選択を管理できます。フォームが不要または読み込めない場合も通常プレイは可能です。報酬広告は任意で、中断・拒否するとその報酬は付与されません。広告を無効にしても処理済みの Google データは削除されません。通常のオフラインプレイはパーソナライズ広告への同意を条件としません。

GitHub と遠隔設定

GitHub 上の公開 JSON で広告の無効・テスト・本番を選択できます。起動、フォアグラウンド復帰、およそ5分ごとに取得する場合があります。保存した進行状況、連絡先、ゲームアカウント識別子は送信しませんが、GitHub は IP など通常の通信情報を受け取ります。このサイトも GitHub がホストします。設定は実行可能なゲームコードを含みません。通信障害、不正・期限切れ設定では新しい広告要求を停止し、表示中の広告は終了まで続く場合があります。

サポートと保管

メールのアドレスと任意に送った内容を返信・調査に使います。パスワードや機微情報は送らないでください。対応、関連問題、適用義務に必要な期間のみサポート情報を保管します。進行状況はリセット・削除まで端末に残り、OS バックアップは別管理です。Google と GitHub の処理・保存期間はそれぞれのポリシーに従い、国外で処理される場合があります。独立したデータ販売事業やゲームプレイ分析サービスは運営しません。

削除・権利・子ども

設定の進行状況リセットで端末のゲーム進行を削除できます。アンインストールで端末のアプリデータは削除されますが OS バックアップは残る場合があります。提供者のログや広告同意記録は削除されません。当方が保有する個人情報へのアクセス・訂正・削除等、適用される権利について連絡できます。提供者管理の情報は提供者への依頼も必要な場合があります。連絡先、写真、マイク、正確な位置の権限を要求しません。子どもが個人情報を提供したと思われる場合はご連絡ください。適用ルールに従って確認・対応します。
