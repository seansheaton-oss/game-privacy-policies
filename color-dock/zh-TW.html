營運者

Color Dock 由 john 營運，聯絡信箱：seansheaton@gmail.com。本政策適用於 iOS 遊戲及其支援與設定網頁。生效日期：2026 年 9 月 30 日。

裝置上的遊戲資料

關卡進度、星星、金幣、道具、外觀、設定、每日挑戰結果及未完成棋盤儲存於裝置。遊戲不提供帳號、聊天或開發者營運的雲端存檔，也不將遊戲存檔上傳至遊戲伺服器。作業系統的裝置備份可能包含應用資料。

廣告與同意

應用整合 Google AdMob 與 UMP。啟用廣告（包括測試模式）時，服務可能處理 IP 位址及推測的概略位置、裝置或應用識別碼、廣告觀看及互動、效能與當機診斷，以提供和衡量廣告、管理同意、維護安全及防範無效流量。實際處理依 SDK、地區與選擇而異。非個人化廣告不代表不收集資料。應用請求非個人化廣告、關閉發布商第一方 ID、不請求 Apple ATT 授權，也不透過應用程式碼讀取 IDFA。Google 與廣告夥伴依其政策處理資料；SDK 聲明包含某些設定下可用於追蹤的裝置識別碼，我們不保證 SDK 完全不處理識別碼。

隱私選擇

UMP 更新同意資訊並在適用時展示表單後，才允許請求廣告。在「設定 > 隱私權政策 > 隱私選擇」管理可用選項。表單不適用或載入失敗不妨礙遊玩。獎勵廣告為自願，拒絕或提早關閉不會獲得該次獎勵。關閉廣告不會刪除 Google 已處理的資料。一般離線遊玩不以同意個人化廣告為條件。

GitHub 與遠端設定

GitHub 託管的公開 JSON 可選擇停用、測試或正式廣告。應用可能於啟動、返回前景及約每五分鐘讀取。請求不含遊戲存檔、聯絡人或遊戲帳號識別碼，但 GitHub 會收到 IP 等一般網路資訊。政策與支援網頁也由 GitHub 託管。設定不包含可執行遊戲程式碼。網路異常、無效或過期設定會停止新廣告請求；已展示廣告可能繼續完成。

支援與保存

來信中的信箱及自行提供的內容用於回覆和排查，請勿傳送密碼或敏感資料。支援資訊僅於處理請求、相關問題及履行適用義務所需期間保存。本機進度保留至重設或移除，系統備份另行管理。Google 與 GitHub 依各自政策處理及保存，可能在境外處理。我們不經營獨立資料銷售或玩法分析服務。

刪除、權利與兒童

「設定 > 清除進度」刪除本機進度；移除應用會刪除本機資料，但系統備份可能留有副本。這不刪除服務商日誌或廣告同意紀錄。可聯絡我們申請存取、更正、刪除所持有的個人資料及行使適用權利；服務商控制的資料可能須另向其申請。不請求聯絡人、照片、麥克風或精確位置權限。若認為兒童向我們提供個人資料，請聯絡以便依法核查處理。
