Color Dock 由 john 运营，联系邮箱：seansheaton@gmail.com。本政策适用于 iOS 游戏及其支持与配置网页。生效日期：2026 年 9 月 30 日。

本机游戏数据

游戏在设备本地保存关卡进度、星星、金币、道具库存、皮肤、设置、每日挑战结果及未完成棋盘。游戏不提供账号、聊天或由开发者运营的云存档，不会把这些存档上传到游戏服务器。操作系统控制的设备备份可能包含应用数据。

广告与同意管理

应用集成 Google AdMob 和 Google UMP。启用广告时（包括测试模式），服务可能处理 IP 地址及由此推断的大致位置、设备或应用标识符、广告展示及互动、性能信息和崩溃诊断，用于广告提供与衡量、同意管理、安全及无效流量防范。具体处理取决于 SDK 行为、所在地区和用户选择。非个性化广告不等于不收集数据。当前应用请求非个性化广告，关闭发布商第一方 ID，不请求 Apple ATT 授权，也不通过应用代码读取 IDFA。Google 及广告合作伙伴可能依其政策处理数据，其 SDK 隐私声明包含在某些配置下可用于跟踪的设备标识符；我们不承诺广告 SDK 完全不处理标识符。

广告隐私选择

UMP 会更新同意信息，并在适用情况下展示表单，之后才允许请求广告。可通过“设置 > 隐私政策 > 隐私选择”查看或修改可用的同意选项。表单不适用或加载失败不影响正常游玩。激励广告自愿观看，拒绝或提前关闭不会获得该次广告奖励。关闭广告不会删除 Google 已处理的数据。标准离线游玩不以同意个性化广告为条件。

GitHub 网页及远程配置

GitHub 托管的公开 JSON 文件可选择关闭、测试或正式广告模式。应用可能在启动、回到前台及约每五分钟获取一次配置。请求不携带游戏存档、通讯录或游戏账号标识，但 GitHub 会收到 IP 地址等正常网络请求信息。政策与支持网页也由 GitHub 托管。配置仅包含设置，不包含可执行游戏代码。网络异常、配置无效或过期时停止新的广告请求；已展示的广告可能继续完成。

支持、共享与保存期限

主动发送支持邮件时，我们会收到你的邮箱及自行提供的内容，用于回复和排查问题。请勿发送密码或敏感信息。支持信息仅在处理请求、解决相关问题及履行适用义务所需期间保存。本机进度保留至重置或移除，系统备份单独管理。Google 与 GitHub 按各自政策决定其数据处理和保存期限，数据可能在你所在国家或地区以外处理。我们不经营独立的数据销售业务，也不提供独立的玩法分析服务。

删除、权利与儿童

“设置 > 清除进度”可清除本机游戏进度；卸载会移除应用本机数据，但系统备份可能保留副本。这些操作不会删除服务商日志或广告同意记录。可联系我们申请访问、更正、删除我们持有的个人信息，并行使适用的隐私权利；由服务商独立控制的数据可能还需向其提出请求。应用不请求通讯录、相册、麦克风或精准位置权限。若认为儿童向我们提供了个人信息，请联系以便按适用规则核查处理。

更新与联系

实践变化时会更新本页面和生效日期；依法需要时会另行通知或征求同意。隐私问题或请求请联系：seansheaton@gmail.com。
